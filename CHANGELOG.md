# Changelog

## [1.0.0] - 2026-11-06

### Added
- Initial release of Lumen, an Online Store 2.0 theme.
- Built-in agentic AI shopping assistant (Mode 1 zero-config + optional Mode 2 LLM proxy).
- Cart drawer with Cart AJAX section re-rendering.
- Predictive search and mobile full-screen search modal.
- Sticky add-to-cart on product pages.
- Full JSON templates, section groups, app-block support, color schemes, and font picker.
- Two presets: Lumen Light and Lumen Noir.
- Homepage sections: hero, featured collection, multicolumn, image with text, rich text, video, testimonials, FAQ, newsletter.
- Customer account templates, password page, gift card template.
- WCAG-oriented accessibility patterns and performance-oriented asset loading.
